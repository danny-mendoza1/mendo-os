# Walter Mendoza - Portfolio

The source code for my personal portfolio, accessible at [wmendoza.dev](https://wmendoza.dev).

## Overview

This portfolio was built to showcase my transition from Support Engineering to Full-Stack Development. It treats the portfolio as a case study in itself—featuring responsive design, CI/CD pipelines, and rigorous type safety.

## Tech Stack

- **Framework:** React 18 (Vite)
- **Language:** TypeScript
- **Styling:** CSS Modules (with scoped variables)
- **Hosting:** Vercel (CI/CD auto-deploy)
- **Testing:** Vitest (Unit testing for utility logic)

## Architecture Highlights

- **Component-Driven:** Reusable UI components (`Card`, `Button`, `Section`) to maintain design consistency.
- **Performance:** optimized assets and code-splitting to ensure high Lighthouse scores.
- **Type Safety:** Strict TypeScript configuration to prevent runtime errors.

## Running Locally

1. **Clone the repository**
   ```bash
   git clone [https://github.com/danny-mendoza1/mendo-os.git](https://github.com/danny-mendoza1/mendo-os.git)
   cd mendo-os
   ```
2. **Install dependencies**
   ```bash
   npm install
   ```
3. **Start development server**
   ```bash
   npm run dev
   ```
